# Student-Studio
The official website and release hub for STUDENT STUDIO — a modern desktop application for student grade management, data visualization, and academic performance analysis.

STUDENT STUDIO 的官方网站及发布中心——一款用于学生成绩管理、数据可视化和学业表现分析的现代桌面应用程序。

This software does not require internet connection, runs fully locally, and stores data locally.
本软件无需联网，完全本地运行，数据本地存储。
